# Goat Farm Layout — Kadapa

An interactive 3D site plan for a small-scale integrated goat-and-hen farm unit,
designed for **one acre in Kadapa, Andhra Pradesh**.

## The concept

Each unit houses **50 goats** on a raised, **elevated slatted deck**. The slatted
floor lets droppings fall through, keeping the goats dry and clean. **Hens live in a
mesh-enclosed run underneath the deck**, sheltered by the structure above and helping
break the parasite cycle by scratching through what falls. Surrounding the housing are
**four rotating exercise paddocks**, grazed one at a time so the others rest and regrow.

The plan is a single self-contained unit that **tiles as ten identical units** to
fill the full one-acre plot.

## Viewing it

This is a single HTML file built with [Three.js](https://threejs.org/). There is
**nothing to install and no build step** — Three.js is loaded from a CDN at runtime.

- **Locally:** open [`index.html`](index.html) in any modern browser.
- **Live:** view it via GitHub Pages (URL added once Pages is enabled).

Drag to orbit, scroll to zoom, and pan to explore the layout in 3D.
